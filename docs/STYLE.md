# House style — sponsor-facing prose

Provenance: ADR-0017; Shell feedback 0001 §5.6, whose field program's
sponsor-facing surfaces drew the verdict "does not read super
coherently in english". Binding on every artefact rendered for the
human sponsor: reports, board summaries, escalation packets, greeting
messages, generated pages. PROSE-enforced: the auditor samples
sponsor-facing artefacts against this page.

1. **Short sentences.** One claim per sentence. If a sentence needs a
   second subordinate clause, split it.
2. **State what a thing is before what is interesting about it.** The
   reader gets the noun first, the commentary second.
3. **No editorializing inside artefacts.** An artefact states facts and
   decisions; enthusiasm, hedging, and asides belong nowhere in it.
4. **Numbers carry their class.** Measured, derived, or relayed
   (PROTOCOL §10) — a derived number presented as measured is a defect,
   not a style slip.
5. **Enforcement claims carry their class.** MACHINE or PROSE, every
   time (ADR-0002, ADR-0016).
6. **Lead with the outcome.** The first sentence of any report answers
   the question the sponsor actually asked; supporting detail follows.
7. **Read it back.** Before reporting an artefact delivered, read it as
   the reader receives it — rendered, not sourced (ADR-0017's read-back
   rule).
