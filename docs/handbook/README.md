# The handbook — a carried copy of the origin program's process document

**What this directory is.** A pinned, byte-identical copy of the three
process volumes written and maintained in the origin program's repository,
`github.com/renatom11/agentic-fpga`, carried inside the shell so that a
deployed copy holds its own explanation — including in an environment that
cannot reach the origin. The shell is the half of the export unit that
runs; these volumes are the half that explains (their §6.0 states the
unit). The three:

- **`PROCESS.md`** — the handbook: every mechanism with the failure class
  it prevents, every enforcement claim with its declared posture.
- **`PROCESS-MEMOIR.md`** — its companion: the superseded record and the
  edition genealogy. History, not law.
- **`PROCESS-STE.md`** — the handbook rendered in Simplified Technical
  English: the rules as short single-meaning sentences an agent can parse
  without a human. Derived, not law.

**Whose record these measure — read before citing.** Every posture stamp,
exhibit, figure and halt-log citation in these volumes is a measurement of
the **origin program's** machinery and record, at the pinned edition below.
None of it is a claim about this shell, about your copy, or about any
project founded from it. `PROCESS.md`'s own top-of-file imperative governs
here with full force: do not import any statement that a control is
mechanically enforced — check it in your own machinery. Its §6.1 fork
contract says exactly what a program adopting these volumes as its own
does with every mark.

**The pin.** Copied byte-identical from the origin at its commit
`9ba1138` — the eighth edition (2026-08-17/18), after its cold-probe
fidelity repairs. **Staleness contract**: this copy is re-carried when the
origin publishes a new edition, or it is stale; the origin's file is the
governing text, and where the two differ the origin's is current and this
copy is old. The origin's edition anchor is in `PROCESS.md`'s head.

**What a founded project does with this directory.** Nothing is required.
It is reference, not law — a project's constitution is `agents/PROTOCOL.md`
and its own charters. Keep it for the reasons (the failure museum and the
failure classes are the part that transfers whole), hand `PROCESS-STE.md`
to a session that needs the rules fast, or delete the directory; none of
the shell's machinery reads it.
